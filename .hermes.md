# MERİDYEN M10 — Hermes Agent project context

This repository uses the **official NousResearch Hermes Agent**. This file is
project context for Hermes running **in the M10 checkout**; it is not a Hermes
fork, new agent executable, paid-LLM configuration or a production deployment.

## Mandatory operating mode

- Research and software-review only. Protect `main`, all S15.3/S16/S16-EA V1.3
  formulas, user profiles, operational databases, original SEC/SimFin archives,
  credentials and untracked files. Work only on a reviewed feature branch.
- At startup use existing read-only Git commands (`git status --short --branch`,
  `git log -1 --oneline`) before any proposed change. Never checkout, merge,
  delete, install, upgrade or push without authorization for that action.
- Default **no external LLM calls** until a specifically pinned model,
  account-level free limits and non-billable settings are independently verified.
  Do not use Hermes native provider fallback, model auto-routing, a second API
  key or a paid provider to bypass a quota. Use the local gated proxy exclusively
  once it has been approved and tested.
- Exactly one reasoning child at a time. The isolated Hermes profile must set
  `delegation.max_concurrent_children: 1`, disable nested delegation, and use
  the approved one-in-flight gateway. Prompt guidance alone is NOT an enforced
  global quota.
- No live trades, automatic production model promotion, user billing activation,
  Google Cloud resource creation, or outbound Telegram messages without
  separate explicit approval and technical verification.
- Distinguish real source checks, simulated scenarios and live connectivity.
  Missing PIT lineage, timestamp, adjusted price, issuer identity, mature labels
  or permission => `INCONCLUSIVE` / `NO_TRADE`, never a fabricated score.

## Six specialist workflows — native Hermes mechanisms

Use project skills from `.agents/skills/meridyen-*/SKILL.md` and Hermes'
official `delegate_task` tool **only after a verified free-model gateway
exists**. A1 is the controller. A2 market discovery, A3 SEC/fundamentals,
A4 catalyst and S16-EA, A5 deterministic data/risk veto, A6 PIT/backtest/
Learning V3 audit. Delegate sequentially, wait for each result before
starting another; pass goal, precise file paths, evidence and scope as
explicit context because children have isolated histories.

Before model access is approved, use **Python first** via the existing bounded
`scripts.hermes_team_tasks` jobs and read-only `phase25i`/`phase25j`
workflows. Those deterministic roles do NOT constitute live reasoning subagents.
No model scores can be copied from plain LLM text or untrusted JSON.

## Safe operational boundary

- Official Hermes native `skills`, `delegate_task`, `cronjob`,
  `terminal`/`execute_code`, and Git worktrees are preferred over writing
  a replacement agent framework.
- Use `HERMES_HOME` pointing to the private isolated M10 profile. The user's
  personal Hermes profile must remain untouched.
- The native zero-LLM two-hour cron is intentionally paused after a successful
  manual run. Do not resume unattended operation without review.
- M10 MCP binds `127.0.0.1:8876` with authentication; it is not a remotely
  connected ChatGPT plugin. Telegram remains disabled without verified
  bot and allowlisted chat.
- Google Cloud deployment remains blocked until every VM/IP/NAT/disk/egress
  SKU and account cost guard can **actually** guarantee zero charge.
